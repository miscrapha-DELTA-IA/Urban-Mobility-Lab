# Diretório de dados

- `raw/`: dados originais privados ou obtidos de fontes autorizadas.
- `processed/`: tabelas derivadas e transformações reprodutíveis.
- `networks/`: grafos OSM, projeções e metadados de extração.

O conteúdo volumoso é ignorado pelo Git. Apenas `.gitkeep` é versionado. Preservar proveniência, termos de uso (incluindo ODbL do OpenStreetMap), consentimentos e restrições de divulgação. **Nunca** commitar gravações identificáveis, credenciais ou dados sensíveis.
